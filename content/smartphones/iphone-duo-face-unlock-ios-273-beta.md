Apple പ്രത്യേക ശ്രദ്ധ കൊടുത്തുകൊണ്ടു വരികയാണ് iPhone Duo foldable device-ന് നിരന്തരം പുതിയ features കൊണ്ടുവരിക എന്നതിൽ. iOS 27.3 beta രണ്ടാം version-ൽ ഈ തവണ കൂടി നല്ല മാറ്റങ്ങൾ കാണാം.

## Face Unlock Feature എന്താണ്?

iPhone Duo-ന്റെ folded state-ൽ unlock ചെയ്യുന്നതിനായി Apple front camera ഉപയോഗിച്ച് facial recognition feature ചേർത്തിരിക്കുന്നു. Settings app-ൽ Touch ID and Passcode menu-ൽ പോയി 'Unlock with Front Camera' option enable ചെയ്‌താൽ ഈ feature ആക്ടിവേറ്റ് ആകും. Device folded state-ൽ ഉണ്ടായിരിക്കുമ്പോൾ നിങ്ങളുടെ face front camera-ൽ കാണിച്ചാൽ device unlock ആകും.

## ഈ Feature-ന്റെ പരിമിതികൾ

ഈ facial unlock feature പൂർണ്ണ സ്വതന്ത്രത നൽകുന്നില്ലെന്നത് ശ്രദ്ധിക്കേണ്ടതാണ്. Lock screen-ൽ മാത്രമായി ഈ feature ഉപയോഗിക്കാൻ കഴിയും. Apple Pay-ൽ payment authenticate ചെയ്യുന്നതിനായി നിങ്ങൾ ഇത് ഉപയോഗിക്കാൻ പാടിലാ. Apps-ന്റെ ভിതരിലെ sensitive operations-ന് ഈ feature പ്രവർത്തിക്കില്ല. ഈ കാരണത്താൽ security യ്ക്കായി പരമ്പരാഗത authentication methods-നെ കൂടുതൽ കൃത്യമായി പരിപാലിക്കേണ്ടതായി ഉണ്ടാകും.

## വായനക്കാരുടെ കാര്യം

കേരളത്തിലും ഇന്ത്യ മുഴുവനുമായി വിതരണം ചെയ്യപ്പെടുന്ന iPhone Duo എന്ന foldable device ഈ update കിട്ടുന്നത് വെറും developers-നു മാത്രം ആയിരിക്കും ആദ്യത്തെ കാലത്ത്. സാധാരണ users-ന് ഈ feature കിട്ടാൻ കുറച്ചു സമയം കൂടി വേണ്ടിവരിക. iOS 27.3-ന്റെ stable version release ആകുമ്പോൾ എല്ലാവര്‍ക്കും ഈ facility ലഭ്യമാകും.

## ഭാവിയിലെ പ്രതീക്ഷ

iPhone Duo പോലുള്ള foldable devices-ൻ്റെ popularity കാണികൊണ്ട് ഭാവിയിലെ updates-ൽ കൂടുതൽ advanced face recognition features കാണാൻ പാടുള്ളതായ സാധ്യതയുണ്ട്. Apple Pay വരെ face unlock extend ചെയ്യാൻ കഴിയുമെന്ന് പ്രതീക്ഷിക്കാം.
