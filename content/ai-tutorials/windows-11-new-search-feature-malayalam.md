Windows 11-ന്റെ ഈ പുതിയ search feature ദ്രുതഗതിയിലും കൂടുതൽ കാര്യക്ഷമതയോടെയും ജോലി ചെയ്യുന്നു. KB5132057 update-ന്റെ ഭാഗമായി നിങ്ങളുടെ computer-ൽ ഈ feature എത്തിയാൽ, search experience തികച്ചും മാറിപ്പോകുന്നതായി നിങ്ങൾ കാണും.

## പുതിയ Search എന്തിനെക്കുറിച്ച് വ്യത്യസ്തമാണ്?

മുൻകാലത്തെ Windows search-ൽ നിങ്ങൾ വെറും files, folders, ആപ്ലിക്കേഷനുകൾ തിരയാൻ പറ്റിയിരുന്നു. എന്നാൽ ഈ പുതിയ version-ിൽ ഇത് വളരെ കൂടി വികസിതമായിരിക്കും. AI-driven suggestions, സിസ്റ്റം settings കണ്ടെത്തൽ, ডോക്യുമെന്റ് സെർച്ച് എന്നിവ കൂടുതൽ കൃത്യമാകുന്നതാണ് പ്രത്യാശ.

## കേരളത്തിലെ ഉപയോക്താക്കൾക്കായി എന്താണ് പ്രഭാവം?

ഇപ്പോൾ ഈ feature English-ിൽ മാത്രം available ആണ്. നിങ്ങൾ Windows 11 ഉപയോഗിച്ച് Malayalam content-കളോ Malayalam named files-കളോ തിരയുകയാണെങ്കിൽ, കുറച്ച് സമയത്തേക്ക് നിങ്ങൾ English search experience-നെ ആശ്രയിച്ചുതന്നെ ജോലി ചെയ്യേണ്ടി വരും. എന്നാൽ Microsoft വരെ ആ കാലത്ത് Malayalam ভাষിയ सपportt കൊണ്ടുവരിയെന്ന് പ്രതീക്ഷിക്കാം.

## ഈ Update വരുന്നത് എങ്ങനെ അറിയാം?

**Settings ഓപ്പൺ ചെയ്യുക** → **Update & Security** → **Windows Update** എന്ന പാതയിൽ ചെന്നാൽ നിങ്ങൾക്ക് വരാനിരിക്കുന്ന അപ്ഡേറ്റുകൾ കാണാൻ പറ്റും. ഈ update സ്വയമായി ഇൻസ്റ്റാൾ ആകുന്നതിനു കൂടുതൽ കാലം എടുതെക്കാം, എന്തെന്നാൽ Microsoft സാവധാനത്തിൽ rollout ചെയ്യുകയാണ്.

## ഉപയോഗകരമായ നുറുങ്ങുകൾ

• നിങ്ങളുടെ Windows device എപ്പോഴും update ചെയ്തുവെയ്ക്കുക
• Search performance മെച്ചപ്പെടുത്താൻ disk space പര്യാപ്തമായി ഉണ്ടെന്ന് ഉറപ്പാക്കുക
• Windows Settings-ിൽ നിന്നും manual update check ചെയ്താൽ ഫലം കൂടുതൽ വരും

ഈ പുതിയ search feature നിങ്ങളുടെ Windows 11 experience കൊതികൂടി എളുപ്പമാക്കും എന്ന് പ്രതീക്ഷിക്കാം.
