## Windows നിങ്ങളുടെ RAM എങ്ങനെ സ്വന്തമാക്കുന്നു?

ാധാരണഗതിയിൽ, Windows ഓപ്പറേറ്റിംഗ് സിസ്റ്റം കതകേ ഏകദേശം 2-3 GB വരെ RAM നിയോഗിച്ചുവെക്കുന്നു. ഇതിൽ ഗ്രാഫിക്സ് മെമോരി, സിസ്റ്റം ക്യാഷ്, ഇന്റিഗ്രേറ്റഡ് ഗ്രാഫിക്സ് കാർഡ്സ് തുടങ്ങിയവ ഉൾപ്പെടുന്നു. നിങ്ങളുടെ ഉപകരണത്തിൽ ഉയർന്ന വിഷയസ്ഥിതിയുള്ള ഗ്രാഫിക്സ് കാർഡ് വേണ്ട പ്രത്യേകിച്ചും ഇന്റിഗ്രേറ്റഡ് ഗ്രാഫിക്സ് ഉള്ളപ്പോൾ, ഈ മാനി വളരെ കൂടുതലാണ്.

## നിങ്ങളുടെ RAM വിനിയോഗം എങ്ങനെ പരിശോധിക്കാം?

ആദ്യം, നിങ്ങളുടെ Windows കമ്പ്യൂട്ടർ എത്രമാത്രം RAM ഉപയോഗിക്കുന്നത് പരിശോധിക്കാം:

• **Task Manager തുറക്കുക**: Ctrl + Shift + Esc കീ സംയോജനം ഉപയോഗിച്ച് വേഗത്തിൽ തുറക്കാം
• **Performance ടാബ് നോക്കുക**: ഇവിടെ നിങ്ങളുടെ മൊത്തം RAM കുറ്റപ്പെടുത്താൻ കഴിയും
• **Processes** ടാബ് പരിശോധിച്ച് നിങ്ങളുടെ ആപ്ലിക്കേഷനുകൾ കുറ്റപ്പെടുത്തുക

## സിസ്റ്റം RAM റിസർവേഷൻ കുറയ്ക്കാൻ ഘട്ടപ്പടികൾ

### Windows Settings-ൽ വിജ്വൽ ഇഫെക്ട്സ് സ്വതന്ത്രമാക്കുക

1. Settings തുറക്കുക (Windows + I)
2. System > About വിഭാഗത്തിലേക്ക് പോകുക
3. "Advanced system settings" തിരയുക
4. Performance വിന്ഡോ തുറന്ന്, "Adjust for best performance" ബട്ടൺ ക്ലിക്ക് ചെയ്യുക
5. "Apply" നൽകി കമ്പ്യൂട്ടർ പുനരാരംഭിക്കുക

### ഇന്റിഗ്രേറ്റഡ് ഗ്രാഫിക്സ് RAM കുറയ്ക്കുക

आपके BIOS സെറ്റിംഗ്സിൽ പ്രവേശിച്ച്:

• ഇന്റിഗ്രേറ്റഡ് ഗ്രാഫിക്സ് മെമോരി 64MB-ലേക്ക് കുറയ്ക്കുക
• "IGPU Memory" അല്ലെങ്കിൽ സമാനമായ സെറ്റിംഗ് തിരയുക
• പരിവർത്തനങ്ങൾ സംരക്ഷിക്കുക

### RAM ഡിസ്ക് അക്ষമാക്കുക

Windows ചിലപ്പോൾ virtual RAM ഡിസ്ക് സൃഷ്ടിക്കുന്നു:

• System Properties > Performance Options > Advanced ടാബ്
• "Virtual memory" വിഭാഗത്തിലെ Change ബട്ടൺ ക്ലിക്ക് ചെയ്യുക
• "No paging file" സെലക്ട് ചെയ്യുക (നിങ്ങളുടെ കയ്യിൽ അധികം RAM ഉണ്ടെങ്കിൽ)

## സാരാംശം

നിങ്ങളുടെ Windows കമ്പ്യൂട്ടരിന്റെ പെരുമാനം വർദ്ധിപ്പിക്കാൻ ഈ മാർഗ്ഗങ്ങൾ ഉപയോഗിച്ച് RAM റിസർവേഷൻ കുറയ്ക്കാൻ കഴിയും. എന്നിരുന്നാലും, ഈ മാറ്റങ്ങൾ വളരെ ജാഗ്രതയോടെ ചെയ്യാൻ ശ്രദ്ധിക്കുക, കാരണം അത് സിസ്റ്റത്തിന്റെ പ്രവർത്തനത്തെ ബാധിച്ചേക്കാം.
