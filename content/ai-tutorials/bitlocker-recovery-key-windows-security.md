## Windows BitLocker എന്താണ്?

BitLocker ഒരു എൻക്രിപ്ഷൻ സമ്പ്രദായമാണ്, ഇത് Windows 10, Windows 11-ൽ കണ്ടെത്താവുന്നതാണ്. നിങ്ങളുടെ ഡ്രൈവിലെ ഡാറ്റ അനുമതി ഇല്ലാത്തവർ കൈവരിക്കാൻ കഴിയാത്തവിധം സുരക്ഷിതമാക്കുന്നു. സാധാരണ കേസുകളിൽ, ഇത് സ്വയമായി പ്രവർത്തിക്കും. എന്നാൽ പിസി രീബൂട്ട് കഴിയാതെ പോയാലോ, പ്രധാന ബിയോസ് സെറ്റിംഗ് മാറിപ്പോയാലോ, Windows നിങ്ങളോട് BitLocker recovery key ചോദിച്ചേക്കാം.

## Recovery Key എവിടെയാണ് സേവ് ചെയ്യപ്പെടുന്നത്?

ഈ കീ സാധാരണയായി നിങ്ങൾ അറിയാത്ത സ്ഥലങ്ങളിൽ സേവ് ചെയ്യപ്പെട്ടിരിക്കാം:

- **Microsoft Account**: നിങ്ങൾ Windows-ന് സൈൻ ഇൻ ചെയ്യുമ്പോൾ ഉപയോഗിച്ച account.microsoft.com ആക്ക്കൗണ്ടിൽ
- **Active Directory**: കോർപ്പറേറ്റ് നെറ്റ്‌വർക്കിലെ കമ്പ്യൂട്ടറുകളിൽ
- **Microsoft OneDrive**: ക്ലൗഡ് സ്ടോറേജിലും സേവ് ചെയ്യപ്പെട്ടിരിക്കാം
- **പ്രിന്റ് ചെയ്ത പേപ്പർ**: നിങ്ങൾ കീ പ്രിന്റ് ചെയ്തിരുന്നെങ്കിൽ

## കീ എങ്ങനെ കണ്ടെത്താം?

ആദ്യമായി നിങ്ങളുടെ Microsoft account-ലേക്ക് login ചെയ്യുക. account.microsoft.com-ൽ പോയി "Device" വിഭാഗത്തിലെ BitLocker സെറ്റിംഗ് നോക്കുക. അവിടെ recovery key കാണാനാകും. എങ്കിലും, ഇത് നിങ്ങൾ കാണാൻ കഴിയാത്ത സ്ഥലത്ത് ഉണ്ടായിരിക്കാം.

കേരളത്തിലെ പലരും അവരുടെ പഴയ ഇ-മെയിൽ അല്ലെങ്കിൽ ബാക്കപ് അകൗണ്ടുകൾ ഭൂലോകം ചെയ്തിരിക്കാം. അങ്ങനെയെങ്കിൽ, ആ അകൗണ്ടുകളെ പരിശോധിച്ച് നോക്കുക.

## സ്വയം കാപ്പി എടുത്തിടുക

നിങ്ങൾ ആ recovery key ഇപ്പോഴുതന്നെ കണ്ടെത്തിയാൽ, അത് ഒരു സുരക്ഷിത സ്ഥലത്ത് കോപ്പി ചെയ്ത് സംരക്ഷിക്കുക. കണ്ടെയ്നർ ഇ-മെയിൽ, കഠിന ഡിസ്ക് ഡ്രൈവ്, അല്ലെങ്കിൽ പേപ്പർ എ കോപ്പി - എന്തെങ്കിലും വഴി സേവ് ചെയ്തിടുക. ഭാവിഷ്യത്തിൽ ആപത്തിൻ സമയത്ത് നിങ്ങൾ കൃതജ്ഞരായിരിക്കും.
