Chrome browser ഉപയോഗിക്കുന്ന ഇന്ത്യൻ ഉപയോക്താക്കൾക്കും മറ്റുള്ളവർക്കും ഒരു പ്രധാന കാര്യം അറിയാം — നിങ്ങളുടെ ബ്രൗസർ പൂർണ്ണമായും നിങ്ങളുടെ നിയന്ത്രണത്തിലുണ്ടെന്ന് വിശ്വാസം കൈവെടുത്തേക്കാം. ഗൂഗിൾ ഒരു കേന്ദ്രീകൃത നിയന്ത്രണ വ്യവസ്థ സ്ഥാപിച്ചിരിക്കുന്നുവെന്ന് സമീപകാലത്തെ അന്വേഷണം വെളിപ്പെടുത്തിയിരിക്കുന്നു.

## Chrome-ലെ ഗൂപ്ത നിയന്ത്രണ സംവിധാനം

Chrome browser-ിൽ നിരവധി hidden pages നിലവിലുണ്ടെന്ന് കണ്ടെത്തിയിരിക്കുന്നു. ഈ പേജുകളിലൂടെ Google കമ്പനി ഉപയോക്താക്കളുടെ browser-ന്റെ പ്രവർത്തനം നിയന്ത്രിക്കുന്നുണ്ട്. Admin panel ഇല്ലെങ്കിലും, ഗൂഗിൾ policies-ഉം നിയമങ്ങളും നേരിട്ട് നിർണ്ണയിക്കുന്നുണ്ട്.

ഈ hidden pages-ലെ വിവരങ്ങൾ കാണാൻ:

• Chrome address bar-ൽ **chrome://policy** type ചെയ്‌താൽ കാണാൻ പാടുള്ള നിരവധി policies കാണാൻ കഴിയും
• **chrome://management** page-ൽ നിങ്ങളുടെ device മാനേജ്‌മെന്റ് സെറ്റിംഗുകൾ ഉണ്ടായിരിക്കും
• ഇതിലൂടെ ഗൂഗിൾ നിങ്ങളുടെ browser-ലേക്ക് എന്ത് നിയമം ബലപ്രയോഗ ചെയ്യുന്നുണ്ട് എന്ന് മനസ്സിലാക്കാൻ പാടുള്ളതാണ്

## ഇത് സാധാരണ ഉപയോക്താക്കെയ്ക് എന്ത് വിധിക്കാണ്?

കേരളത്തിലെയും ഇന്ത്യയിലെയും വലിയ സംഖ്യ ആളുകൾ Chrome ഉപയോഗിക്കുന്നു. പലരും അറിയാതെ തന്നെ Google-ന്റെ നിയന്ത്രണങ്ങൾക്ക് വിധേയരാകിയിരിക്കും. ഇതിൽ വലിയ ആശങ്ക എന്താണെന്നാൽ, നിങ്ങളുടെ personal data എങ്ങനെ ব്യവഹരിക്കപ്പെടുന്നു എന്നതുമായി ഈ നിയന്ത്രണം ബന്ധപ്പെട്ടിരിക്കുന്നു.

## നിങ്ങൾ എന്തുചെയ്യാൻ പാടുള്ളത്?

തടസ്സങ്ങളിൽ നിന്ന് സുരക്ഷിതരായിരിക്കാൻ ചില പരിശോധനകൾ നടത്തുക:

• **chrome://policy** ചെക്ക് ചെയ്യുക — നിങ്ങളുടെ browser-ൽ നിലവിലുള്ള policies കാണാൻ കഴിയും
• Firefox അല്ലെങ്കിൽ Brave പോലുള്ള ബദൽ browser-ൽ മാറാൻ ആലോചിക്കുക
• Chrome മാത്രം ഉപയോഗിക്കുന്നെങ്കിൽ, വലിയ വിവരങ്ങൾ പങ്കിടാതിരിക്കുക

ഗൂഗിൾ സ്വരാജ്യത്തിന്റെ വികാസത്തിലും കൂടെയ്ക്കാണ് വർത്തിക്കുന്നത്. എന്നിരുന്നും, നിങ്ങളുടെ ഡിജിറ്റൽ സ്വാതന്ത്ര്യം സംരക്ഷിക്കുന്നത് ഈ കാലത്തിൻറെ അത്യാവശ്യ കർത്തവ്യം.
