സോഷ്യൽ മീഡിയയിൽ ഇപ്പോൾ ഏറ്റവും കൂടുതൽ ഷെയർ ചെയ്യപ്പെടുന്ന AI ഫോട്ടോകൾ ഏതൊക്കെ? **Nano Banana** — ഒരു ചെറിയ വിരലിൽ ഒതുങ്ങുന്ന കൊച്ചു വാഴപ്പഴം. ഇത് AI ഉണ്ടാക്കിയതാണ് — ഒരു Prompt കൊണ്ട്!

## Nano Banana Viral ആകാൻ കാരണം

AI-generated miniature photography ഇന്ന് X (Twitter), Instagram, Reddit-ൽ ദശലക്ഷങ്ങൾ കാണുന്നു. ഒരു tiny object — ഒരു banana, ഒരു coffee cup, ഒരു car — macro lens-ൽ capture ചെയ്ത ഫോട്ടോ പോലെ AI ഉണ്ടാക്കുന്നു.

ഇത് viral ആകാൻ കാരണം ഇതിന്റെ **hyperrealism** — AI ഫോട്ടോ ആണെന്ന് മനസ്സിലാകില്ല!

## Google Gemini-യിൽ Nano Banana Prompt

**Gemini Imagen 3** ഉപയോഗിക്കാൻ: gemini.google.com → Image Generation

### Exact Prompt (Copy ചെയ്യൂ):

```
A hyperrealistic macro photograph of an extremely tiny banana, 
only 1cm long, resting on a human fingertip. 
Shot with a 100mm macro lens, f/2.8 aperture. 
Soft natural window light. 
Photorealistic, 8K resolution, sharp details on the banana texture.
```

**Malayalam-ൽ prompt നൽകണമെങ്കിൽ:**

```
ഒരു മനുഷ്യന്റെ വിരൽ തുമ്പിൽ ഇരിക്കുന്ന 1 സെന്റിമീറ്റർ മാത്രം 
നീളമുള്ള അതിചെറിയ വാഴപ്പഴം. Macro photography style. 
Hyperrealistic, natural light.
```

## ChatGPT DALL-E 3-ൽ ഉള്ള Prompt

```
Photorealistic image: an impossibly tiny yellow banana, 
miniature size (1cm), sitting on a wooden table next to 
a regular coin for scale. Macro photography, 
bokeh background, studio lighting, ultra detailed.
```

## Prompt Engineering ടിപ്‌സ്

മികച്ച Nano Photo ഉണ്ടാക്കാൻ ഈ keywords ഉപയോഗിക്കുക:

- `hyperrealistic` / `photorealistic`
- `macro photography` / `100mm macro lens`
- `8K resolution` / `ultra detailed`
- `soft bokeh background`
- `natural window light` / `studio lighting`
- `for scale` (coin, finger, pencil കൂടെ ചേർക്കുക)
