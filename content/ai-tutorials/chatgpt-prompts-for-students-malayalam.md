AI ഉപയോഗിച്ച് പഠിക്കുന്നത് cheating അല്ല — smart learning ആണ്. ഇവിടെ 20 prompts copy ചെയ്ത് ഉപയോഗിക്കൂ.

## 📚 Essay & Assignment Writing

**1. Essay ഉണ്ടാക്കാൻ:**
```
Write a 500-word essay on [topic] for a Class 10 student. 
Use simple English. Include introduction, 3 main points, conclusion.
```

**2. Malayalam Essay:**
```
[വിഷയം]-നെ കുറിച്ച് Class 10-ന് അനുയോജ്യമായ 
400 വാക്കുകളിൽ ഒരു ഉപന്യാസം Malayalam-ൽ എഴുതൂ.
```

**3. Assignment Introduction:**
```
Write an engaging introduction for my assignment on [topic]. 
Make it interesting and informative. 100 words max.
```

---

## 🔬 Concepts മനസ്സിലാക്കാൻ

**4. Simple Explanation:**
```
Explain [concept] as if I'm a 15-year-old student. 
Use a simple real-life example from India.
```

**5. Malayalam-ൽ Explain:**
```
[concept] Malayalam-ൽ ലളിതമായി വിശദീകരിക്കൂ. 
ഒരു ഉദാഹരണം ഉൾപ്പെടുത്തൂ.
```

**6. Comparison:**
```
What is the difference between [topic A] and [topic B]? 
Give me a simple table comparison.
```

---

## 📝 Exam Preparation

**7. Important Questions:**
```
Give me 10 most important questions from [chapter name] 
in [subject] for [board] Class [number] exam.
```

**8. One-line Answers:**
```
Give me one-line answers for all key definitions 
in [chapter]. Keep it simple for quick revision.
```

**9. MCQ Practice:**
```
Create 10 multiple choice questions from [topic] 
with answers. Difficulty level: medium.
```

**10. Mock Test:**
```
Create a 20-mark test paper for [subject] Chapter [number]. 
Include 2-mark and 5-mark questions.
```

---

## ✏️ Note Making

**11. Summary Notes:**
```
Summarize [chapter/topic] in bullet points. 
Maximum 15 points. Easy to memorize.
```

**12. Mind Map Ideas:**
```
Give me a mind map structure for [topic] 
with main branches and sub-branches.
```

**13. Malayalam Notes:**
```
[Chapter]-ന്റെ പ്രധാന points Malayalam-ൽ 
bullet points ആക്കി തരൂ. SSLC exam-നു വേണ്ടി.
```

## 🤔 Doubt Clearing

**14. Math Problem:**
```
Solve this math problem step by step and explain 
each step clearly: [paste your problem]
```

**15. Grammar Check:**
```
Check this English paragraph for grammar mistakes 
and explain what was wrong: [paste your paragraph]
```

## 💼 Project Work

**16. Project Introduction:**
```
Write an introduction for my school project on [topic]. 
Include importance, objectives, and scope. 200 words.
```

**17. Bibliography:**
```
Create a bibliography/reference list for a project 
on [topic] in APA format. Include 5 sources.
```

## 🎯 Pro Tips

- **Be specific**: "Explain photosynthesis for Class 9 CBSE" — GPT-4o-യേക്കാൾ മികച്ച ഉത്തരം
- **Follow up**: "More examples please" / "Simpler explanation"
- **Verify**: ChatGPT-ന്റെ ഉത്തരം textbook-ൽ confirm ചെയ്യുക
- **Malayalam**: "Malayalam-ൽ പറഞ്ഞുതരൂ" — ChatGPT Malayalam നന്നായി അറിയാം
