## Subject-wise AI Tips

### 🔬 Biology (NEET)

**Doubt clearing:**
```
Explain the difference between mitosis and meiosis 
with a simple diagram description. 
NEET level explanation, important points to memorize.
```

**Mnemonics:**
```
Give me memory tricks (mnemonics) for remembering 
the 12 Cranial Nerves for NEET Biology.
```

### ⚗️ Chemistry

**Reaction mechanism:**
```
Explain SN1 vs SN2 reaction mechanism step by step.
Include conditions, examples, and NEET MCQ tips.
```

**Formula help:**
```
List all important formulas from Physical Chemistry 
Chapter: Thermodynamics. NEET focused, with examples.
```

### 📐 Physics (JEE/NEET)

**Concept clarity:**
```
Explain Bernoulli's theorem with real-life Kerala examples.
Show mathematical derivation step by step.
Common mistakes students make in JEE exam.
```

## Mock Test Generate ചെയ്യാൻ

```
Create a 10-question MCQ test on Human Physiology 
for NEET. Difficulty: Medium-Hard.
Include correct answers and explanations.
Mix of direct questions and application-based.
```

**Daily practice:**
```
Give me 5 NEET-level MCQs on [today's topic].
After I answer, tell me what I got wrong and why.
```
