Figma പ്ലാറ്റ്‌ഫോം വീണ്ടും ഒരു പ്രധാനപ്പെട്ട അപ്‌ഡേറ്റ് അവതരിപ്പിച്ചിരിക്കുന്നു. ഈ മാസത്തിൽ, കമ്പനി AI agents-നായി പുതിയ ഫീച്ചറുകൾ പ്രഖ്യാപനം ചെയ്തിരിക്കുന്നു, ഇത് ഡിസൈൻ പ്രോസെസിനെ കൂടുതൽ സ്വയങ്ങൾ പ്രവർത്തിക്കാനുള്ള കഴിവ് നൽകുന്നു.

## പുതിയ ഫീച്ചറുകൾ എന്തൊക്കെ?

Figma-യിലെ AI agents-ൻ്റെ പെരുമാറ്റം നിയന്ത്രിക്കാനായി വിവിധ പ്യാരാമീറ്ററുകൾ സെറ്റ് ചെയ്യാൻ കഴിയും. ഈ നിയന്ത്രണ വ്യവസ്ഥകൾ ഡിസൈനർമാർക്ക് കൂടുതൽ പ്രിസിশൻ നൽകുന്നു. ഫ്ലോ എവിടെ പോകണമെന്ന് കൃത്യമായി നിർദ്ദേശിക്കാൻ ഡിസൈന്നർമാർ ഇപ്പോൾ കഴിയും.

## Code Layers: പ്രോഗ്രാമിംഗ്ലോകത്തിലേക്കുള്ള കടന്നുകയറ്റ്

Code Layers ഫീച്ചർ ഡിസൈൻ എবം കോഡ് ലെയെരിംഗ് കൂടിച്ചേർക്കുന്നു. ഇത് ഡെവലപ്പറുകൾക്കും ഡിസൈനർമാർക്കും തമ്മിലുള്ള സഹകരണം കൂടുതൽ സുഗമമാക്കുന്നു. ഈ ഓപ്പൺ ബീറ്റ ഫേസ് ছোട്ട കമ്മ്യൂണിറ്റി ബ്യവഹാരിങ്ങിലേക്ക് പങ്കെടുക്കാൻ നിലയുണ്ടാക്കുന്നു.

## ഇന്ത്യയിലെ ഡിസൈനർമാർക്കുള്ള പ്രാധാന്യം

ഇന്ത്യയിലെ സ്ടാർട്ടআപ്പുകളും ക്രിയേറ്റിവ് ഏജൻസികളും Figma-യെ വ്യാപകമായി ഉപയോഗിക്കുന്നു. ഈ പുതിയ AI-চാലിത ഫീച്ചറുകൾ ഇവരുടെ പ്രൊജെക്ട് ഡെലിവറി വേഗത വർദ്ധിപ്പിക്കും. പ്രത്യേകിച്ച്, കേരളത്തിലെ ഗ്രാഫിക്സ് ഡിസൈൻ സ്ടുഡിയോകൾക്ക് ഇത് ഉത്തരണ്ടാകും.

## എങ്ങനെ ഇത് സഹായകമാണ്?

• **വേഗത്തിലുള്ള ഓട്ടോമേഷൻ**: ആവർത്തിച്ചുള്ള നിർമ്മാണ സൃഷ്ടിക്കൽ സ്വയംഭരണ ആയി ചെയ്യാൻ കഴിയും
• **സാഹിത്യ കമ്മ്യൂണിക്കേഷൻ**: ഡിസൈനർമാർ വ്യക്തമായി agents-നെ നിർദ്ദേശിക്കാൻ പറ്റും
• **കോസ്ട് കാര്യക്ഷമത**: നിയമിതരിൽ ശ്രദ്ധ കേന്ദ്രീകരിക്കാനാവും

Code Layers-ൻ്റെ ഓപ്പൺ ബീറ്റ നിലനിൽപ്പ് ഇതായിരുന്നു യഥാർത്ഥ ഉപയോഗകാരിമാർ അഭിപ്രായം കാണാനുള്ള ഒരു സംയുക്തമായ പരിശീലനമെന്നു തന്നെ പരിഗണിച്ചിരിക്കുന്നു. എത്തവും ആളുകൾ ഈ ഫീച്ചർ നിരീക്ഷണം ചെയ്യുകയും അവരുടെ അഭിപ്രായ ഫീഡ്‌ബാക്ക് നൽകുകയും ചെയ്യണം.
