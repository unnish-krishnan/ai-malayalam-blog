## WhatsApp — Meta AI Memory Feature

**Biggest update**: Meta AI ഇനി **remember** ചെയ്യൂ!

**How it works:**
```
User: "Meta AI, I'm planning a trip to Munnar next month"
[Later]
User: "Give me travel tips"
Meta AI: "For your Munnar trip next month, here are tips..."
```

**What Meta AI remembers:**
- Personal preferences shared
- Ongoing plans mentioned
- Family details (if shared)
- Work context
- Past conversations reference

**Privacy control:**
- Settings → Meta AI → Memory → View/Delete
- Specific memories: Delete individual items
- Full reset: Clear all memory

**Rolling out**: US, Canada first → India (3-6 months)

**Feature in development** (Beta testing):

**What it does:**
- Message type ചെയ്‌ത് future date/time set ചെയ്യൂ
- Personal chats + **group chats** both
- Reminders: Auto-send on schedule

**Use cases:**
```
✅ Birthday wishes: "Happy Birthday!" → schedule midnight
✅ Business: Invoice reminder → schedule payment due date
✅ Groups: Meeting reminder → send 1 hour before
✅ Announcements: Event info → send morning of event
✅ Kerala festival greetings: Onam wishes → schedule morning
```

**How (when released):**
1. Long press message bubble → Schedule
2. Select date/time
3. Confirm → Message queued
4. Phone online ആകണം at send time (or WhatsApp servers handle)

**Expected release**: Q4 2026
